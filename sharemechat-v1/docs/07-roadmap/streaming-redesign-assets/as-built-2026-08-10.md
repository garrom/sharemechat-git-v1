# As-built — Rediseño Streaming + Sistema de Regalos (2026-08-10)

> Estado: **HECHO y desplegado en TEST**. Rama `feat/streaming-layout`, **sin push a origin ni nivelar a main** todavía (pendiente decisión del operador).
> Mocks de referencia: `docs/07-roadmap/streaming-redesign-assets/mocks/` (`streaming-layout-propuesta.html`, `gift-bar-sobre-video.html`).
> Antecedente directo: rediseño de favoritos puro + sistema de regalos base en `docs/07-roadmap/gift-redesign-assets/`.

## 1. Objetivo

Unificar el aspecto y la experiencia de **todas las superficies de vídeo** (videochat random + llamadas 1-a-1 de favoritos) y llevar el **sistema de iconos/regalos** (con efectos) a todas ellas, estilo LiveJasmin: vídeo apaisado a ancho completo, chat a un lado, y regalos como barra sobre el vídeo.

## 2. Superficies afectadas (5 componentes)

| Componente | Rol | Superficie |
|---|---|---|
| `VideoChatRandomCliente.jsx` | Cliente pagador | Videochat random |
| `VideoChatRandomModelo.jsx` | Modelo | Videochat random |
| `VideoChatRandomUser.jsx` | Cliente **trial** (role USER) | Videochat random (gancho) |
| `VideoChatFavoritosCliente.jsx` | Cliente | Chat P2P favoritos + llamada 1-a-1 |
| `VideoChatFavoritosModelo.jsx` | Modelo | Chat P2P favoritos + llamada 1-a-1 |

Dashboards que orquestan: `DashboardClient`, `DashboardModel`, `DashboardUserClient`.

## 3. Bloques del rediseño

### 3.1 Vídeo apaisado + blur (todas las llamadas)
- El área de vídeo ocupa **todo el ancho** (se quitó el tope de 1040px de `StyledCallCardDesktop` vía `data-full`).
- El vídeo va `object-fit: contain` (proporción real, no recorta) y el **letterbox** se rellena con un **blur del propio stream**: `StyledRemoteVideoBlur` (vídeo mudo secundario, mismo `MediaStream`, `object-fit: cover` + `filter: blur`, `z-index:-1`).
  - Random: se engancha vía `blurVideoRef` sobre el prop `remoteStream`.
  - Llamadas favoritos: no hay `callRemoteStream` como prop → se sincroniza el `srcObject` del vídeo principal al blur en su `onPlaying`.
- PiP (cámara propia) reducido en streaming: `StyledCallLocalVideo[data-compact]` (18%/190px).
- Radio de la card en llamada = **0** (esquinas rectas); fullscreen = **icono** (`faExpand`) en todas.

### 3.2 Chat a un lado (llamadas desktop)
- La card pasa a **fila**: `[vídeo | columna de chat]` vía `StyledCallCardDesktop[data-chat-side]` (dirección row) + `[data-full]` (llenar alto con flex, sin franja negra).
- Nueva columna: `StyledCallChatColumn` / `StyledCallChatColHeader` / `StyledCallChatColScroll` (cabecera con avatar+nombre+"Ver original" botón, mensajes, composer).
- Móvil: se mantiene el chat overlay (no columna).

### 3.3 Barra de regalos y controles SOBRE el vídeo (llamadas desktop)
Barra inferior **única** superpuesta al vídeo (`StyledCallStage`), `renderCallOverlayBar`:
- **IZQUIERDA** (`StyledCallOverlayControls`): colgar / siguiente / favorito (icono **corazón** `faHeart`), botones ~34px.
- **CENTRO** (`StyledCallOverlayGifts`): barra de regalos en **UNA fila** (`StyledGiftBar[data-surface="video-overlay"]`, pill semitransparente + blur), chips **50×56px** con el **precio debajo** del icono (sin taparlo), **sin scroll**.
- **DERECHA** (`StyledCallOverlayRb`): reportar / bloquear (solo random; favoritos no tiene).
- **Efectos** (`StyledGiftFxLayer`, z5) montados en `StyledCallStage` → serpentina/confeti/corazones **sobre el vídeo**.

### 3.4 Sistema de iconos/regalos unificado (portado de favoritos puro)
- Barra Gratis+Pago en **UNA fila** (se quitó el segmento "Gratis/Regalos"), tanto en chat puro como sobre el vídeo.
- Regalo de pago (PREMIUM) → **modal de confirmación**; gratis (QUICK) → envío directo.
- **Caritas fuera** de la barra de regalos (`FACE_GIFT_CODES` en `GiftIcon.jsx`: flirty, hot, kiss, laugh, love, ok, sad, wow, basic) — ya están en el **selector de emojis** (`EmojiTextPicker`, botón 😊). Se quedan los objetos (heart, star, fire, sparkle/Destello, rosebud, labios).
- 🎁 quitado del `EmojiTextPicker` (confundía con el regalo de pago).
- Mensajes-regalo pintados con el componente **`GiftIcon`** (SVG por código / emoji), no con URL remota (arreglaba iconos rotos tipo "Destello").
- Regalos alineados **por emisor** (mío derecha / peer izquierda), como los globos de texto.
- Emoji suelto = grande sin globo (`isSingleEmoji`).

### 3.5 HUD del modelo en llamada de favoritos
`SessionHUD variant="model"` (timer + ganancia por tiempo + suma de regalos). Requirió:
- `DashboardModel` pasa `modelEconomics` a `VideoChatFavoritosModelo`.
- Acumulador `giftsSumEur` (regalos del cliente durante la llamada, %reparto `modelEconomics.giftModelSharePct`).

### 3.6 Trial (VideoChatRandomUser) — vista de gancho
- **Misma vista** que el cliente (vídeo+blur+columna de chat) como gancho de conversión, pero **todo bloqueado**: input/enviar/regalo → `onGoPremium` ("hazte cliente"). Tarjeta con candado.
- i18n: `dashboardUserClient.videoChatRandomUser.teaser.{chatLocked,cta,inputLocked}` (es/en).
- Barra azul `TrialFreeBanner` oculta en llamada desktop (CTA ya en la columna).
- **Bug corregido (clave)**: el trial no pasaba `data-tab` a `DashboardShell` → el layout crecía sin límite. `<DashboardShell data-tab={activeTab}>` lo acota a 100vh como cliente/modelo.

## 4. Matriz de envío/recepción de regalos por superficie

| Superficie | Cliente envía | Modelo envía | Nota |
|---|---|---|---|
| Random | Pago + gratis | **NO** (centro barra vacío) | Backend `MatchingHandlerSupport.handleGiftInMatch` rechaza `senderRole != client`: random es unidireccional **CLIENT→MODEL**. El modelo recibe efectos y envía emojis. |
| Favoritos (chat puro / llamada) | Pago + gratis | **Sí, solo gratis** | Socket P2P (`msgSocket`) sí permite MODEL→CLIENT gratis. |
| Trial (random USER) | Bloqueado (gancho) | — | Todo → `onGoPremium`. |

## 5. Componentes / estilos clave (VideochatStyles.js)

- `StyledCallCardDesktop[data-full]` (ancho+alto completo) y `[data-chat-side]` (fila con columna).
- `StyledRemoteVideoBlur`, `StyledRemoteVideoMedia[$contain]`, `StyledCallLocalVideo[data-compact]`.
- `StyledCallChatColumn` / `StyledCallChatColHeader` / `StyledCallChatColScroll`.
- `StyledCallOverlayBar` / `StyledCallOverlayControls` / `StyledCallOverlayGifts` / `StyledCallOverlayRb`.
- `StyledGiftBar[data-surface="video-overlay"]` (una fila, pill semitransparente, chips 50×56 precio debajo, sin scroll).
- `StyledGiftFxLayer` (z5, capa de efectos sobre el vídeo).
- `DashboardShell` acotado a 100vh por `IS_APP_TAB(data-tab)` (el trial ahora sí lo pasa).
- `GiftIcon.jsx`: `FACE_GIFT_CODES` / `isFaceGiftCode` (fuente única de caritas a excluir), `resolveGiftSlug`, alias `destello→sparkle`.

## 6. Restricciones / decisiones abiertas (compliance/producto)

- **Modelo NO envía regalos en random** (limitación de backend, ver matriz). Si se quisiera permitir regalos-objeto gratis MODEL→CLIENT en random, hace falta tocar `MatchingHandlerSupport.handleGiftInMatch`. Decisión de producto.
- **Aviso "sesión supervisada"** (moderación IA, GDPR/DSA, `DEC-13 P2.1`) es **solo-modelo por diseño**. El operador preguntó si debe verlo el cliente → decisión legal pendiente, **no tomada** (no es maquetación).
